# Handwritten Digit Classification

Builds a machine learning pipeline to classify handwritten digit images (0-9), working with a deliberately messy grayscale image dataset (missing labels, noisy/empty samples).

## Contents

- `notebook.ipynb` — data cleaning, preprocessing, model training and evaluation.
- `report.pdf` — write-up of the approach and results.

## Running it

```bash
pip install scikit-learn pandas numpy datasets
jupyter notebook notebook.ipynb
```
